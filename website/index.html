The AI behind this project

Meet WorkBuddy

WorkBuddy is Tencent's AI agent for everyday office work — a desktop workspace, not just a chat window. One sentence, and it plans and does the task for you.

What this project adds

WorkBuddy normally stops at digital work. Our connector adds the physical side: meeting-room lights, indicators and sensors join the same conversation. No second app, no dashboard.

Good to know: WorkBuddy is a desktop app you install — the web version cannot run custom MCP connectors. See the 3-step setup below for the account, installer, and +350 free credits. No separate AI API key needed.

WorkBuddy is a desktop app. The browser version cannot run MCP connectors, so the desktop client is required.

The whole setup in one line

WorkBuddy Desktop → MCP → ESP32

No AI model or API key runs on the board. WorkBuddy thinks; ArduBuddy sends one checked command to the ESP32, and the board replies with what happened.

Three steps. That's it.

Everything starts in your browser. The connector is just one small file.

1

Flash the board

Plug the ESP32 into your computer. Open the setup page and click one button.

2

Join your Wi-Fi

Type your Wi-Fi name and password on the same page. We show the board's address when ready.

3

Talk to WorkBuddy Desktop

Run ArduBuddy.exe, paste the address, then say "Set up the meeting room." in the desktop app.

No AI runs on the board

A WorkBuddy account is required, but you need no separate AI API key, model, or subscription. WorkBuddy reasons; the connector sends one allowlisted command to the ESP32. That's the whole chain.

What you need

Flashing runs in the browser with Chrome or Edge. The ArduBuddy.exe connector is currently Windows-only.

Hardware

  • An ESP32 Dev / WROOM board
  • A USB cable that carries data (not charge-only)
  • Up to 4 AC lamps or loads, within the relay rating — mains voltage, handle with care
  • A 2.4 GHz Wi-Fi network (no 5 GHz)
  • A certified relay module in an enclosure with a fuse, wired by a competent electrician

Software

  • Chrome or Edge on HTTPS (Web Serial)
  • Windows for the ArduBuddy.exe connector
  • WorkBuddy Desktop installed and signed in — the web version cannot run MCP connectors (steps)
  • A WorkBuddy account; the invite link gives +350 free credits
  • Nothing else — no Python, no Arduino IDE, no drivers
